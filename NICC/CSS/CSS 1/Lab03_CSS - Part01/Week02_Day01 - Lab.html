Folder Structure

Ensure your files are organized correctly inside your project directory:

portfolio-lab/
├── css/
│   └── style.css
├── index.html
└── profile.jpg
1

Link your CSS

Add the following line inside the <head> section of your index.html file:

<link rel="stylesheet" href="css/style.css">
2

Styling the Page

Create css/style.css and add the following code:

/* 1. Global Styles (Element Selectors) */ body { font-family: Arial, Helvetica, sans-serif; /* CSS Fonts lesson */ line-height: 1.6; color: #333333; background-color: #f9f9f9; margin: 0; } /* 2. Header & Navigation (Class Selectors) */ .header { background-color: #ffffff; padding: 20px; } .nav-link { text-decoration: none; /* Removes underline */ color: #2563eb; font-weight: bold; margin-right: 15px; } .nav-link:hover { color: #1e40af; text-decoration: underline; } /* 3. Hero Section (ID Selector) */ #hero { background-color: #ffffff; text-align: center; /* Centers text and image */ padding: 50px 20px; } #hero-title { font-size: 40px; color: #111827; } .hero-subtitle { font-size: 1.2rem; /* Using rem units */ color: #6b7280; } /* 4. Images */ img { border: 5px solid #2563eb; /* Border property */ margin-top: 20px; } /* 5. Sections */ section { padding: 40px 20px; } h2 { border-bottom: 2px solid #2563eb; display: inline-block; padding-bottom: 5px; margin-bottom: 20px; } /* 6. Form Basics */ .form-group label { display: block; font-weight: bold; margin-bottom: 5px; } input, textarea { width: 100%; padding: 8px; font-size: 16px; border: 1px solid #ccc; } /* 7. Buttons (Class Selectors) */ .btn-primary { background-color: #2563eb; color: white; padding: 10px 20px; border: none; font-weight: bold; cursor: pointer; } .btn-secondary { background-color: #e5e7eb; color: #374151; padding: 10px 20px; border: none; }
